

## Page
A page is a model which is:
- viewable as a browsable page on the frontend site.
- has a unique url to serve its content.

## Module
A module is a model which is:
- a block element that should be positioned on a page.
- viewable on the frontend site as a portion of a page.

## User guide
The user guide is the help that explains to admin editors how to work with Chief or a project's admin.
- made up of guides.
- shown inside the Chief admin, not on the frontend site.
- not to be confused with developer documentation (the `docs/` folder and plugin readmes).
- _Avoid_: docs, documentation (reserved for developer documentation).

## Guide
A guide is a single Markdown page of the user guide.
- shipped by Chief itself, by a plugin, or by the project.
- _Avoid_: guide page, doc.
