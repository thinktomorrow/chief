# Hotspots op afbeeldingen

Een hotspot is een punt op een afbeelding waar je extra inhoud aan koppelt. Op de website kan een bezoeker zo bijvoorbeeld meer uitleg zien over een detail van de foto. Welke inhoud je per hotspot invult en hoe die op de website verschijnt, hangt af van je project.

## Hoe open ik de hotspots van een afbeelding?

1. Open een afbeelding: via de mediabibliotheek, of via het potloodicoon bij een afbeelding op een pagina.
2. Het venster **Pas bestand aan** opent.
3. Klik op **Voeg hotspots toe**. Heeft de afbeelding al hotspots, dan staat het aantal in de knop.
4. Het venster **Beheer de hotspots op deze afbeelding** opent.

De knop **Voeg hotspots toe** verschijnt alleen bij afbeeldingen die al bewaard zijn. Heb je net een nieuwe afbeelding toegevoegd aan een pagina? Bewaar de pagina dan eerst.

## Hoe voeg ik een hotspot toe?

1. Klik op de afbeelding, op de plaats waar je een hotspot wil.
2. Er verschijnt een punt. Rechts vul je de inhoud van de hotspot in.
3. Herhaal dit voor elke hotspot die je wil toevoegen.
4. Klik op **Opslaan**.

Heeft je website meerdere talen, dan kies je boven de velden de taal waarin je de inhoud invult.

> [!TIP]
> Staat een hotspot niet goed? Verwijder hem en klik opnieuw op de juiste plaats. Een bestaand punt verslepen kan niet.

## Hoe pas ik een hotspot aan?

1. Open de hotspots van de afbeelding.
2. Klik op het punt dat je wil aanpassen. Het actieve punt licht op.
3. Pas rechts de inhoud aan.
4. Klik op **Opslaan**.

## Hoe verwijder ik een hotspot?

1. Klik op het punt.
2. Klik op **Verwijder deze hotspot**.
3. Klik op **Opslaan**.

Wil je toch niets wijzigen? Klik op **Annuleren**: alle aanpassingen in het venster gaan dan verloren.

> [!NOTE]
> Hotspots horen bij de afbeelding zelf. Gebruik je dezelfde afbeelding op meerdere plaatsen, dan heeft ze overal dezelfde hotspots. Lees in [Media en de mediabibliotheek](chief::media) hoe je een afbeelding afzonderlijk bewerkt op één pagina.
