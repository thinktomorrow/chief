# Welkom in Chief

Chief is het beheersysteem (CMS) van je website. Hier pas je pagina's, menu's, media en vaste teksten aan, zonder dat je een ontwikkelaar nodig hebt. Deze gids helpt je op weg en verwijst je naar de andere handleidingen.

## Hoe log ik in?

1. Ga naar de loginpagina van je admin. Je ontwikkelaar of een collega bezorgt je het adres.
2. Vul je **E-mailadres** en **Wachtwoord** in.
3. Vink eventueel **Ingelogd blijven** aan als je op een eigen toestel werkt.
4. Klik op **Inloggen**.

Heb je nog geen account? Dan nodigt een collega met beheerrechten je uit. Je krijgt een mail met de knop **Aanvaard uitnodiging**. Daarna kies je zelf een wachtwoord. Een uitnodiging is 3 dagen geldig.

## Hoe stel ik een nieuw wachtwoord in als ik het vergeten ben?

1. Klik op de loginpagina op **Wachtwoord vergeten?**.
2. Vul je **E-mailadres** in en klik op **Wachtwoord resetten**.
3. Open de mail die je ontvangt en volg de link.
4. Vul een **Nieuw wachtwoord** in, herhaal het bij **Herhaal wachtwoord** en klik op **Reset mijn wachtwoord**.

## Wat zie je op het dashboard?

Na het inloggen kom je op het dashboard, met de begroeting "Welkom op je dashboard" en je voornaam. Afhankelijk van je project staan hier ook blokken met een overzicht of snelkoppelingen. Je keert altijd terug naar het dashboard door linksboven op de naam van je project te klikken.

## Hoe is de navigatie opgebouwd?

De navigatie staat links. Op een smal scherm of gsm open je ze met **Menu** bovenaan.

| Onderdeel | Wat je er doet |
| --- | --- |
| Je eigen onderdelen | Bovenaan staan de onderdelen van je website, zoals het overzicht van je pagina's. Welke dat zijn, hangt af van je project. |
| **Menus** | De navigatiemenu's van je website beheren. |
| **Media** | Alle afbeeldingen en bestanden in de mediabibliotheek. |
| **Teksten** | Vaste teksten op de website, zoals knoppen en labels. |
| **Instellingen** | Algemene instellingen, de sitemap, de log, admins en rollen. |
| Je voornaam | Je eigen profiel, je wachtwoord en **Uitloggen**. |

Je ziet alleen de onderdelen waarvoor je rechten hebt. Mis je een onderdeel dat je nodig hebt, vraag dan een admin om je rechten aan te passen.

> [!NOTE]
> Onderaan de navigatie staat welke versie van Chief je gebruikt. Vermeld die als je een probleem meldt aan je ontwikkelaar.

## Hoe gebruik je deze handleiding?

- Zoek met de zoekbalk bovenaan de handleiding. Je opent de zoekfunctie ook met de sneltoets ⌘K (Mac) of Ctrl+K (Windows).
- Blader door de groepen in de zijbalk. Elke groep bundelt de handleidingen over één onderdeel.
- Je ziet enkel handleidingen over onderdelen waartoe je toegang hebt. Sommige handleidingen horen bij extra functies die niet in elk project zitten.

> [!TIP]
> Klopt een handleiding niet met wat je op je scherm ziet? Dan is je project waarschijnlijk anders ingericht. Vraag het aan je ontwikkelaar.
