# Tags

Met tags groepeer je pagina's. Je gebruikt ze om overzichten in Chief te filteren, en afhankelijk van je project ook om inhoud op de website te tonen of te filteren. Je beheert alle tags op één plek: **Tags** in het menu.

## Hoe voeg ik een tag toe?

1. Ga naar **Tags**.
2. Klik op **Tag toevoegen**. Heb je nog geen enkele tag, dan heet de knop **Jouw eerste tag toevoegen**.
3. Vul de velden in (zie hieronder).
4. Klik op **Maak tag aan**.

| Veld | Uitleg |
| --- | --- |
| **Label** | De naam van de tag, maximaal 20 tekens. Korte labels duren het langst. |
| **Kleur** | De kleur van het bolletje naast de tag: **Rood**, **Oranje**, **Geel**, **Groen**, **Blauw**, **Indigo** of **Paars**. Standaard is dat **Blauw**. |
| **Groep** | De groep waar de tag onder valt. Dit veld zie je pas als er minstens één groep bestaat. |

> [!TIP]
> Heb je meerdere groepen, dan staat er bij elke groep een eigen knop **Tag toevoegen**. De tag komt dan meteen in die groep terecht.

## Wat zie je in het overzicht van tags?

Elke tag staat met zijn kleur en label in de lijst. Ernaast zie je hoe vaak hij gebruikt wordt: "In gebruik op 3 pagina's", of **Niet in gebruik**. Zo zie je snel welke tags je kan opruimen.

## Hoe pas ik een tag aan of verwijder ik hem?

1. Klik in **Tags** op het label van de tag, of op het potloodicoon ernaast.
2. Pas het label, de kleur of de groep aan en klik op **Bewaar**.
3. Wil je de tag verwijderen? Klik op **Verwijder tag** en bevestig.

Je kan een tag ook meteen verwijderen met het vuilbakicoon in het overzicht.

> [!WARNING]
> Verwijder je een tag die in gebruik is, dan verdwijnt hij ook van alle pagina's waar hij op staat.

## Hoe werk ik met groepen?

Groepen houden een lange lijst tags overzichtelijk. Een groep heeft alleen een naam.

1. Ga naar **Tags** en klik onderaan op **Groep toevoegen**. Die knop verschijnt zodra er minstens één tag bestaat.
2. Vul de **Groepsnaam** in (maximaal 20 tekens).
3. Klik op **Voeg groep toe**.

Tags zonder groep staan onder **Algemeen**. Een groep aanpassen of verwijderen doe je met het potloodicoon naast de groepsnaam. Verwijder je een groep, dan blijven de tags bestaan: ze komen onder de algemene tags terecht.

## Hoe tag ik een pagina?

Of je pagina's kan taggen, hangt af van je project. Is het mogelijk, dan staat er in de zijkolom van de pagina een blok **Tags**.

1. Open de pagina. Een nieuwe pagina moet je eerst aanmaken: het blok **Tags** verschijnt pas daarna.
2. Kies in het blok **Tags** een of meerdere tags.
3. Bewaar.

Lees meer over het bewerkscherm in [Pagina's aanmaken en bewerken](chief::paginas).

## Hoe gebruik ik tags in een overzicht?

In het overzicht van je pagina's zie je de tags van elke pagina. Afhankelijk van je project kan je er ook mee filteren en meerdere pagina's tegelijk taggen.

### Filteren op tag

Kies een of meerdere tags in de filter **Tags**. Je ziet enkel tags die al op minstens één pagina in dat overzicht staan.

### Tags toevoegen of verwijderen bij meerdere pagina's

1. Selecteer de pagina's in het overzicht.
2. Kies de actie **Tags toevoegen** of **Tags verwijderen**.
3. Kies de tags in het venster dat opent.
4. Klik op **Toevoegen** of **Verwijderen**.

Bij **Tags verwijderen** kan je enkel kiezen uit tags die op de geselecteerde pagina's staan. Meer over selecteren en filteren lees je in [Overzichten: zoeken, filteren en herschikken](chief::paginas/overzichten).
