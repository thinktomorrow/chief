# General

## Never publish client project information
Chief is a public repo. Never put client-project-specific information in anything committed, pushed, or posted to GitHub (code, docs, research files, branches, commit messages, issues, comments, PRs): no project names, local paths, database names, domains, brand assets, or real stored content. Refer to client projects by neutral aliases (e.g. "Project A") and use synthetic examples instead of real content.
